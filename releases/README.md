# Clippy for Mac: latest release

**[Clippy-1.2.0.dmg](Clippy-1.2.0.dmg)** is the latest version. The same file is on the [Releases page](https://github.com/easter478/clippy-mac/releases/latest), along with the notes for each version.

You need a Mac with **Apple silicon (M1 or later)** and **macOS 14 Sonoma or newer**.

## Install

1. Download `Clippy-1.2.0.dmg` (click the file above, then **Download raw file**).
2. Open it and drag **Clippy** onto **Applications**.
3. Open **Applications**, **right-click Clippy → Open**, then click **Open** again.
   - Clippy isn't notarised by Apple, so the first launch needs this extra step.
   - If macOS only offers **Done** or **Move to Bin**: **System Settings → Privacy & Security**, scroll down, click **Open Anyway** next to Clippy.
4. Clippy appears on your desktop and as a paperclip in the menu bar. Click him.
5. **First run:** the chat offers to download a Qwen model (about 2.5 GB for the suggested one). After that, chat runs entirely on your Mac.
